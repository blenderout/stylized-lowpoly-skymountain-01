# Stylized LowPoly Mountain Runner & Terrain Pack



🗻 All 3D models, script, skybox, and terrain in this package are custom-built and cleared for commercial and personal Unity projects. Final PBR terrain maps incorporate baked public-domain (CC0) texture data.

## Description

### ✅ Key Features

1. **Infinite Terrain Rolling System**: 1K tris, road and environment modules automatically populating themself to construct an endless runner environment.

2. **Stylized Offroad Vehicle**: 4K tris, low-poly camo offroad 4x4 vehicle with separated wheels, ready for custom physics or arcade driving controllers. Includes a simple bumpy effect script

3. **Lowpoly Nature Pack**: ~0.5K tris. Including trees, rocks, dead trunk, flowers, grass clumps.

4. **Custom Stylized Skybox**: a bright, vibrant cloud skybox that matches the semi-stylized aesthetic of the environment.

5. **PBR Materials**: clean PBR textures, 2K (2048x2048). Plus, packed/optimized textures for mobile friendly.

6. **Demo Scene Included**: an infinite rolling terrain, lighting setup, and asset layout.

### 📦 Package Contents & Technical Scope

- 🧩 Heightmap/Stamps included, plus: deposit mask, wear (erosion) mask, and slope mask. Perfect for terrain splatmap texturing.
- 🏔️ Environment module objects:
  - ×3 Large mountain environment meshes.
    - Mobile optimization (~1k tris/each)
    - High Polygon (~130k tris/each)
    - Clean splatmap: deposit + wear + slope masks
  - ×3 Small hill environment meshes.
    - Mobile optimization (~1k tris/each)
    - High Polygon (~130k tris/each)
    - Clean splatmap: deposit + wear + slope masks
- 🏝 Game-ready objects
  - ×3 Mountainous modules. (~10k tris/each)
  - ×3 Alpine/dirt road modules. (~13k tris/each)
  - ×3 Road modules, side view. (~13k tris/each)
  - ×1 Skymountain, 360° view. (~30K tris/each)
  - ×1 Off-road vehicle with particle effects; tire trail. (~4k tris/each)
  - ×1 Millitary aircraft. (~4k tris/each)
  - ×18 Nature objects: trees, rocks, dead trunk, flowers, grass clumps. (~0.5k tris/each)
  - ×1 Daylight casual skybox.
